## How to get the code

**Option A — Download as ZIP (no git required)**

1. Click the branch dropdown on this page
2. Select the branch you want (e.g. `chat-agent/phase1-done`)
3. Click **Code** → **Download ZIP**
4. Unzip and follow the README inside the project folder

**Option B — Clone a specific branch**

```bash
git clone --branch chat-agent/phase1-done --single-branch https://github.com/yuqiaoyan/ai-builder-bootcamp.git
```

Then follow the `README.md` inside the project folder for setup instructions.
