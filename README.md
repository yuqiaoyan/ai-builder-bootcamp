# Granola Prototype — Starting Point

A single-file clone of the Granola note-taking app, used for the Week 1 PM prototyping demo. We add a line-tagging feature to it and try different UX interactions.

## How to use

1. Download this folder (green **Code → Download ZIP** button above).
2. Double-click `index.html` to open it in your browser — no setup, no install.
3. Follow along as we prompt Claude to add tagging and explore interaction designs.
