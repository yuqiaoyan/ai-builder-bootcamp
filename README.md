# Chat Agent — Starting Point

This is the empty starting state for the Week 2 build-along. It contains only the ChatGPT UI screenshots we'll give the AI as a visual reference while planning the app.

## How to use

1. Download this folder (green **Code → Download ZIP** button above).
2. Open it in VS Code and start Claude Code.
3. Follow along with the planning demo — you'll create the product spec, tech spec, and progress files from here.

The `Screenshots/` folder has the reference images of the ChatGPT interface we're cloning.
